The manufacturer document DS-000069 revision 1.2 (2016-08-29) supplies the
sensor timing, modes, and interface characteristics. The UE0149 schematic
supplies the module circuit connections, and the board artwork supplies the
visible signal labels. The EMMIC-ICS43434 file describes a separate
breakout board.
